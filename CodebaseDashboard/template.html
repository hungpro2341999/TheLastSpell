Hàng là nơi sử dụng, cột là nơi được sử dụng. Ô đậm hơn có nhiều liên kết script hơn.

Quan hệ của từng script

Chọn một script để xem kế thừa, triển khai interface và hai chiều phụ thuộc. Bấm “Khai báo” hoặc “Xem mã” để xem bằng chứng.

Số liệu là phép phân tích tĩnh gần đúng: C# dựa trên kiểu/namespace nội bộ và khai báo lớp/interface, Python dựa trên import, Batch dựa trên đường dẫn script. Kiểu ngoài project hoặc tên trùng chưa phân giải được đánh dấu riêng.

Chạy lại py -3 tools\codebase_dashboard.py để cập nhật.
